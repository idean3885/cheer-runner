# ADR 0011. 구간은 지점을 지나는 순간 닫히고, 메인 계기판은 평균 페이스다

- 상태: 채택
- 날짜: 2026-08-20
- 관련: `docs/DOMAIN.md` 페이스·템포 정책, `docs/MVP.md` 첫 릴리스 범위

## 맥락

실기기에서 달려 본 결과 두 가지가 어긋났다.

1. **기록 달리기에는 구간 페이스가 아예 생기지 않는다.** 구간은 도달 판정에서만 닫히는데, «여기 표시» 로 만든 지점은 이번 달리기에 울리지 않으므로 도달이 없다. 첫 달리기에서 지점을 아무리 찍어도 지점 사이 페이스가 기록되지 않고, 그것을 보여 줄 화면도 없다. 요약은 저장만 되고(`appendRun`) 읽는 곳이 없다.
2. **메인 계기판이 30초 창 페이스라 지점을 찍을 때마다 다시 재는 것처럼 보인다.** 실제로는 어떤 경로도 누적을 재설정하지 않지만, 순간값이 출렁이는 것이 러너에게 재측정으로 읽힌다.

## 결정

**구간은 지점을 지나는 순간 닫힌다.** 지나는 순간은 셋이다.

| 닫는 순간 | 언제 | 근거 |
|---|---|---|
| 도달 판정 | 따라가기 달리기에서 목표 반경 안 | 기존 규칙 그대로 |
| 달리며 지점 생성 (`markHere`) | 기록 달리기에서 그 자리를 표시할 때 | 생성한 자리가 곧 지나는 자리다 |
| 종료 | 이미 닫힌 구간이 하나라도 있을 때 | 마지막 지점부터 종료까지도 구간이다 |

지도 지정(`pin`)은 닫지 않는다. 지나지 않은 자리를 예약하는 행위라서다.

**메인 계기판은 전체 평균 페이스를 계속 보여 준다.** 어떤 지점 행위도 이 값을 재설정하지 않는다. 현재(창) 페이스는 보조로 내려가고, 진행 중 구간의 페이스는 하단 지점 목록 자리에서 실시간으로 갱신된다.

## 결과

- 기록 달리기와 따라가기 달리기가 같은 형태의 구간 기록을 남긴다. "그 언덕 구간이 8분 10초" 가 첫 달리기부터 성립한다
- 종료 뒤 화면이 그대로 종료 요약이 된다. 경로(지도) · 전체 거리·시간·평균 페이스 · 구간 목록이 한 화면에 있다
- 도달 기록(`arrivals`)과 구간 기록(`splits`)이 나뉜다. 도달은 응원과 순번 판정의 근거이고, 구간은 집계다. 하나로 합치면 기록 달리기의 생성 구간이 도달 순번을 오염시킨다
- 달리기 기록 목록(과거 달리기 조회)은 이 결정 밖이다. [MVP.md](../MVP.md) 의 미룸 항목 그대로 둔다
