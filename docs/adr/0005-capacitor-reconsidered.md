# ADR 0005. 시험 자산이 생긴 뒤 캐패시터를 다시 검토하고 다시 기각한다

- 상태: 채택
- 날짜: 2026-08-12
- 관련: [ADR 0001](0001-cross-platform-choice.md) (유지), [ADR 0004](0004-replay-adapter.md)

## 맥락

ADR 0001 이 캐패시터를 기각한 근거는 "재작성 공수가 문제되지 않는다" 였다. 그 전제가 바뀌었다.

달리기 중 수집이 1.34km 에서 끊기는 사고가 나면서, 프로토타입에 브라우저를 실제로 띄우는 자동 시험 14개를 붙였다. 실측 전에 결함 3건을 잡았고 배포 게이트가 됐다.

이것이 자산이 되면서 계산이 달라졌다. **캐패시터는 같은 페이지를 WebView 에 담으므로 이 시험이 살아 있고, RN 은 페이지를 버리므로 시험도 같이 버린다.** 전제가 바뀌었으므로 다시 봐야 했다.

## 결정

**캐패시터를 다시 기각한다. ADR 0001 은 그대로 유지한다.**

배경 위치를 계속 받을 수 있는가 하나가 결정했다. 정본 문서를 확인했다.

| 항목 | 캐패시터 | Expo |
|---|---|---|
| 공식 위치 플러그인의 배경 지원 | 직접 지원하지 않는다고 명시 | 배경 위치 수신 API 1차 지원 |
| 배경 실행 수단 | 호출당 약 30초, 시점 보장 없음, 호출 간 상태 유지 없음 | 배경 작업으로 위치 묶음 단위 수신을 계속 유지 |
| 안드로이드 반복 간격 | 최소 15분 | 해당 없음 |

30분 달리기에 몇 초 간격 위치가 필요하다. 30초 단발과 15분 간격으로는 이 앱이 성립하지 않는다.

커뮤니티 구현이 있으나 쓰지 않는다. **WebView 자바스크립트가 배경에서 도는지가 확인되지 않았고, 그게 정확히 이 프로젝트가 해결하려는 문제다.** 웹에서 안 되는 것을 확인해 네이티브로 가는데 여전히 WebView 에 담으면 같은 벽을 다시 만날 수 있다.

## 결과

기각으로 잃는 것은 시험 **경우**가 아니라 시험 **배관**이다.

| 자산 | RN 으로 |
|---|---|
| 도메인 규칙, 시험 표본, 판정 기준 | 옮겨간다. 문서와 데이터라서 그대로 쓴다 |
| 브라우저 구동 배관 약 160줄 | 버린다. [ADR 0004](0004-replay-adapter.md) 의 재생 어댑터가 자리를 대신한다 |
| 원본 게이트 5개 | 문자열 검사에서 의존 방향 검사로 형태를 바꿔 옮긴다 |

버리는 것은 배관 한 층이고, 그 층은 ADR 0004 가 이미 설계해 둔 자리다.

**받아들이는 대가는 도메인 규칙이 두 곳에 구현되는 구간이다.** 웹의 계산 코드와 앱의 순수 접기 연산(fold)이 같은 규칙을 각각 담는다. 규칙이 바뀌면 두 곳을 고쳐야 한다. 웹을 언제 정리할지는 [MVP.md](../MVP.md) 의 익스팬드 전략에 적는다.

**이 재검토를 다시 꺼낼 때는 캐패시터의 공식 배경 위치 지원 여부부터 확인한다.** 그것이 바뀌지 않았으면 결론도 바뀌지 않는다.

프로토타입에서 플랫폼 호출을 창구 넷으로 모은 작업은 기각과 무관하게 남는다. 포트 경계의 근거로 [ARCHITECTURE.md](../ARCHITECTURE.md) 에 반영했다.
